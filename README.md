# AutoSpec | Elite Automotive Intelligence 🚗⚡

AutoSpec is a modern automotive intelligence and comparison platform built with Streamlit. It offers comprehensive vehicle specifications, intelligent analytics, dynamic test-drive / consultation bookings, and administrative management backed by a relational database (MySQL / TiDB Cloud).

---

## 🚀 Features

- **Automotive Intelligence & Analytics**: In-depth specifications, luxury & performance metrics, and vehicle comparisons.
- **Dynamic Booking System**: Real-time consultation, test drive, and service booking with dynamic slot validation.
- **Admin Management Dashboard**: Manage vehicle inventory, audit bookings, and export database backups.
- **Multi-Environment Database Connectivity**: Seamless support for local MySQL and zero-configuration cloud relational databases (TiDB Cloud Serverless, AWS RDS).
- **Responsive Streamlit UI**: Dark mode UI tailored with custom branding and styling.

---

## 🛠️ Tech Stack

- **Frontend & App Framework**: [Streamlit](https://streamlit.io)
- **Data & Processing**: Python, Pandas
- **Database**: MySQL / TiDB Cloud Serverless (`mysql-connector-python`)

---

## 📦 Getting Started

### 1. Prerequisites
- Python 3.10+
- MySQL or a free [TiDB Cloud Serverless](https://tidbcloud.com) database

### 2. Installation
Clone the repository and install the dependencies:
```bash
git clone <your-repo-url>
cd "YAP Automotives"
pip install -r requirements.txt
```

### 3. Run Locally
```bash
streamlit run app.py
```
