# AutoSpec Vehicle Images Directory

Place local vehicle images here to display high-resolution photos in the **Car Details** and **Book a Car** tabs.

### File Naming Convention
Image filenames should follow the format:
`<Brand>_<Model>.jpg` (with spaces replaced by underscores)

#### Examples:
- `BMW_M4.jpg`
- `BMW_X5.jpg`
- `Audi_RS_e-tron_GT.jpg`
- `Audi_Q7.jpg`
- `Mercedes-Benz_C_Class_AMG.jpg`
- `Mercedes-Benz_G_Class.jpg`
- `Volvo_XC90.jpg`
- `Jaguar_F-Pace.jpg`

If a local image is not found, AutoSpec automatically generates an ultra-modern vehicle placeholder badge.
